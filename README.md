# HataBan（はたばん）— 旗当番表メーカー

小学校の PTA 地区委員・校外委員のための、旗当番（登校時の旗振り当番）の年間割り振り表を作るソフトです。
「Excel なのにカレンダーを手入力し、曜日ズレを数人がかりでダブルチェックする」という手作業を、名簿と期間の入力だけで終わらせます。

- **単一バイナリ**: 実行ファイル1つだけ。インストール不要、依存ゼロ（Go 標準ライブラリのみ）。
- **完全オフライン**: 通信は一切しません。画面は自分のパソコンのローカルサーバー（127.0.0.1）から開きます。
- **名簿は端末の外に出ません**: 世帯名・登校班などの名簿データは、自分のパソコン内の1ファイルにだけ保存されます。外部に送信されることは一切ありません。
- **祝日は自動計算**: 日本の国民の祝日をルールで計算します（振替休日・国民の休日にも対応）。カレンダーの手入力と曜日ズレのチェックは不要です。

## 起動方法

```
./hataban
```

ブラウザが自動で開きます（開かない場合は表示される `http://127.0.0.1:8791` などの URL を開いてください）。終了はターミナルで Ctrl+C です。

コマンド:

```
./hataban              Web UI を起動（既定）
./hataban export csv [ファイル名]   現在の当番表を CSV で書き出す
./hataban export ics [ファイル名]   現在の当番表を iCalendar (.ics) で書き出す
./hataban version      バージョン表示
```

## 使い方

1. **期間と休業日**: 年度の開始日と終了日を入れます。対象日は平日（月〜金）から祝日を除いた日で、運動会の振替休日など学校独自の休業日は「休業日」に追加してください。
2. **地点**: 旗当番の地点（正門前、交差点など）を登録します。
3. **名簿**: 世帯ごとに、登校班・担当できる地点・不可曜日（月曜不可など）を入れます。Excel からの貼り付け（タブ区切り／カンマ区切り）にも対応しています。地点に何もチェックが無い世帯は「どの地点でも可」として扱います。
4. **割り振りを生成**: ボタン1つで、各日・各地点に1世帯ずつ割り振ります。
   - 担当できない地点・不可曜日には割り当てません。同じ世帯が同じ日に複数地点に入ることもありません。
   - 担当回数は世帯間でなるべく均等になるように割り振ります。
   - どうしても割り当てできない枠がある場合は、黙って飛ばさず、理由つきで画面に表示します。
5. **手直しと出力**: 生成後、個別の割り当てはプルダウンで別の世帯に変更できます（制約に反する変更は理由を表示して受け付けません）。世帯別の担当回数も一覧で確認できます。出力は A4 印刷表示・CSV・iCalendar (.ics) に対応しています。

## データの置き場所

データは端末内の1ファイルだけに保存されます。外部に送信されることはありません。

- 既定: OS のユーザー設定フォルダ配下の `HataBan/hataban.json`
  - Windows: `%APPDATA%\HataBan\hataban.json`
  - macOS: `~/Library/Application Support/HataBan/hataban.json`
  - Linux: `~/.config/HataBan/hataban.json`
- 環境変数 `HATABAN_DATA_DIR` を指定すると、そのフォルダに保存します。

## ビルド

Go 1.22 以降が必要です。

```
go build -o hataban .
go test ./...
```

## 注記

- 祝日計算は現行の「国民の祝日に関する法律」のルールに基づきます。法改正があった場合は計算結果が実際と異なる可能性があります。また春分の日・秋分の日は 1980〜2099 年に有効な近似式で計算しています。
- 学校行事による休業日・登校日（土曜登校など）は学校ごとに異なるため、休業日は利用者が追加する形にしています。土曜・日曜は対象日に含まれません。
- 本ソフトは割り振りの案を作る支援ツールです。最終的な当番表の確認は各学校・PTA の運用に合わせて行ってください。
